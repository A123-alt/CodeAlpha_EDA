CodeAlpha Exploratory Data Analysis Project

Overview

This project performs exploratory data analysis on an illustrative student performance dataset.

Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

Analysis Performed

- Dataset preview and structure
- Missing-value and duplicate checks
- Descriptive statistics
- Subject-wise average scores
- Correlation analysis
- Visualizations of average scores and study hours

Dataset

The dataset contains illustrative student names, study hours, attendance percentages, and subject scores. It does not represent actual student records.

How to Run

1. Install Python.
2. Install dependencies with "python -m pip install -r requirements.txt".
3. Run "python main.py".

Output

The analysis report and graphs are saved in the "outputs" folder.
